# xolugg-tradelab
Herramienta simple de apoyo para tradeo en EA SPORTS FC 27 Ultimate Team: cálculo de beneficio, ROI, watchlist y seguimiento de operaciones.

## Versionado

XoluGG TradeLab usa Semantic Versioning:

- 0.9.0: desarrollo previo a la primera versión estable.
- 1.0.0: primera versión estable.
- 1.0.1: corrección compatible.
- 1.1.0: nueva funcionalidad compatible.
- 2.0.0: cambio mayor.
